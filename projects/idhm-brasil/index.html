03 / REPRODUTIBILIDADE

Dados, método e limitações

01

Fonte dos dados

Atlas do Desenvolvimento Humano no Brasil (PNUD, Ipea, FJP), a partir dos censos de 1991, 2000 e 2010.

Fonte oficial ↗
02

Tratamento

Python e pandas validam chaves e ausências; reorganizam o painel município-ano; calculam médias simples, variações e rankings; exportam JSON para este dashboard.

Ver código da análise ↗
03

Limitações importantes

A geografia municipal histórica foi harmonizada para os limites de 2010. Médias municipais NÃO são ponderadas pela população e NÃO equivalem ao IDHM oficial do Brasil. Variações descritivas não estabelecem causalidade.

Capturas reais da versão atual do Power BI. O relatório ainda passa por revisão; as imagens não são um painel incorporado ao site.

DESIGN COM PROPÓSITO

Informação primeiro. Decoração depois.

Organizei o relatório em camadas: panorama do torneio, rankings e detalhamento dos confrontos. O objetivo é permitir leitura rápida e, ao mesmo tempo, exploração mais profunda.

A versão final incluirá filtros testados, nomes padronizados e documentação completa.

03 / DAXMEASURES

Indicadores reproduzíveis

Medidas simples, com definição clara, são preferíveis a visuais impressionantes com cálculos inconsistentes.

// Total de partidas
Partidas =
DISTINCTCOUNT(matches[match_id])

// Gols: dois lados do confronto
Gols =
SUM(matches[home_score_fulltime])
+ SUM(matches[away_score_fulltime])

// Média de gols
Media = DIVIDE([Gols], [Partidas])

Código ilustrativo: substitua 'matches' pelo nome físico da consulta no PBIX.

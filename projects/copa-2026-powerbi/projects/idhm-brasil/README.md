# Human Development in Brazilian Municipalities (1991–2010)

> An exploratory data analysis of historical municipal development using the Atlas do Desenvolvimento Humano no Brasil (PNUD / Ipea / FJP).

**[Open the interactive case study](./index.html)** (live when this repository is published through GitHub Pages).

## Business / research question

How did municipal human development change across Brazil between 1991 and 2010, and which indicators and municipalities stand out?

## Objectives

1. Evaluate changes in the Municipal Human Development Index (IDHM) at the municipality level.
2. Compare income, education and longevity indices.
3. Identify the municipalities with the highest indices in 2010 and the largest *absolute* gains since 1991.
4. Document methods and limitations so that other analysts can reproduce the work.

## Key findings (descriptive)

| Finding | Result |
|---|---:|
| Municipalities analysed | 5,565 |
| Census years | 1991, 2000, 2010 |
| Mean IDHM across municipalities, 1991 | 0.381 (unweighted) |
| Mean IDHM across municipalities, 2010 | 0.659 (unweighted) |
| Mean difference, 1991–2010 | +0.278 index points |
| Highest IDHM, 2010 | São Caetano do Sul (SP), 0.862 |
| Largest IDHM absolute change, 1991–2010 | Bodó (RN), +0.493 |

**These municipal averages are NOT Brazil's population-weighted official national IDHM.** The official national IDHM figures are 0.493 (1991) and 0.727 (2010) in the Atlas series.

The municipal mean of the education dimension rose by approximately 0.380 index points, exceeding the changes in the income and longevity dimensions in the same index units. This is a descriptive comparison, *not* causal attribution to the composite indicator.

## Dataset

- **Original:** Atlas do Desenvolvimento Humano no Brasil — 2013 municipal panel, based on IBGE population censuses.
- **Organizations:** United Nations Development Programme (PNUD), Instituto de Pesquisa Econômica Aplicada (Ipea), Fundação João Pinheiro (FJP).
- **Links:** <https://www.atlasbrasil.org.br/> and <https://www.undp.org/pt/brazil/idhm-municipios-2010>.
- **File:** `data/idhm_municipios_1991_2000_2010.csv`.
- **Grain:** municipality–year, with 16,695 records (5,565 x 3 years).
- **Variables:** `ANO`, `Codmun7`, `Codmun6`, `Municipio`, `UF_sigla`, `UF`, `IDHM`, `IDHM_E`, `IDHM_L`, `IDHM_R`.

The CSV included here is a **simplified extract** prepared from the downloaded Atlas workbook for this learning project. The original workbook should be treated as the authoritative source.

## Reproduce the analysis

Python 3.10+ is recommended:

```bash
python -m pip install -r projects/idhm-brasil/requirements.txt
python projects/idhm-brasil/scripts/analyze_idhm.py
```

The script validates column presence, 2010-based municipal panel coverage, duplicates, missing values and 0–1 indicator bounds, then regenerates `data/idhm_dashboard.json`. This JSON powers the browser-only interactive dashboard (`index.html` and `dashboard.js`).

No private datasets, API keys, external database or paid services are needed.

## Methods and limitations

- Index values range from 0 to 1. **Absolute change** is calculated as `IDHM_2010 - IDHM_1991` in index points, not percentages.
- The Atlas historical series uses **municipal geographies harmonized to the 2010 territorial framework**, enabling comparisons for 5,565 units. This does not imply all 5,565 municipalities existed administratively in 1991.
- Municipal means are **unweighted**; a small municipality and a populous city receive equal weight. They must not be presented as the official country or state IDHM.
- The dashboard uses descriptive statistics only; differences cannot establish the causal effect of policy interventions.
- These observations are historical (1991–2010) and **must not be described as current rankings in 2026**.
- Rankings may include tied index values. Sorting equal values alphabetically is a presentation convention, not a meaningful difference in rank.

## Recommended extensions

- Write a deeper study of regional inequality with properly sourced population weights.
- Add spatial visualization using an IBGE shapefile and disclose the geographical harmonization choices.
- Complement historical comparisons with separately sourced, more recent indicators rather than mixing incompatible IDHM vintages.

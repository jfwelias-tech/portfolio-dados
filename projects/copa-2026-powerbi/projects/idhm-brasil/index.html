03 / REPRODUCIBILITY

Data, methods & limitations

01

Data source

Atlas of Human Development in Brazil (UNDP/PNUD, Ipea, FJP), derived from the 1991, 2000 and 2010 population censuses.

Official source ↗
02

Processing

Python and pandas validate keys and missingness; reshape a municipality-year panel; compute unweighted averages, differences and rankings; export JSON for this static dashboard.

View analysis code ↗
03

Read carefully

Historical municipal geography is harmonized to 2010 boundaries. Municipal means are NOT population-weighted and are NOT Brazil's official national IDHM. Changes are descriptive and do not establish causality.

Read methodology ↗

Project authored as a learning case study. Analysis scripts, source data and limitations are public so results can be independently checked.

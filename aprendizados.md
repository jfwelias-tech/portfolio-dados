# Meus aprendizados sobre Git

Comandos no GIT que aprendi sozinho:
pwd			Mostra em qual pasta você está.
ls			Lista os arquivos da pasta atual.
cd nome-da-pasta	Entra em uma pasta.
cd ..			Volta uma pasta..

1. Git permite controlar diferentes versoes de um projeto.
2. O comando git status mostra as alteracoes nos arquivos.
3. O comando git commit registra uma versao do projeto.
